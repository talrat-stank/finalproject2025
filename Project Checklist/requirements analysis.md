# Sequenced Drum Machine Requirements Analysis

### Description

A drum machine set to a grid of 4 measures of 4/4. There is a bpm slider at the top of the page and 3 channels that can be used. The user can change what file is played in each channel, but the default is kick, snare, and hi-hat. Below the grid is 3 blocks for each channel, which can alter the said channel's gain, delay wet/dry, and reverb wet/dry. I might add sliders that affect the delay and reverb sliders more if I have time.

### Use Cases

The use case is to have a simple drum machine wherever you go.

### System Requirements

Everything must be able to run simultaneously and without affecting or altering each other.

### Constraints and Limitations

The time it might take to finish every layer should be considered. Ensuring everything is properly connected and using effects seperately.
