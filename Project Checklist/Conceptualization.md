# Conceptualization

## Drum Machine Sequencer

1. 3 channels and 8 measures of an interactive drum sequencer.

2. The user can insert their own files for each channel, but the default is kick, snare, and hihat.

3. BPM slider above the sequence blocks.

4. Sliders that change a channel's gain, reverb wet/dry, and delay wet/dry. Maybe also a slider for the delay feedback rate (and feedback gain if I have time).

5. Effect sliders and played file can be changedin a section below the sequence blocks. There will be 3 divided sections for each channel.
